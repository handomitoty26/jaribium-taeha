# 태하관자리비움기록v1

태하관(남학생 기숙사) 야간 자습 중 자리 비움(화장실·물 보충 등)을 기록하는 태블릿용 PWA입니다.
사감 책상 위 태블릿에서 학생이 학번 네 자리를 누르고 확인 → 사유를 고르면 "자리 비움", 돌아와서 학번을 누르면 "복귀"가 기록됩니다.

## 쓰는 법

1. 처음 열면 **설정**에서 이 태블릿의 자습실 학년(1·2·3학년 또는 전체)을 고릅니다.
2. **명단**에서 아침점호에 넣는 남학생 방배정 명렬표 엑셀을 불러옵니다(`남학생방배정` 또는 `학번순방배정공지` 시트의 학번·이름·호실 칸만 읽음).
3. 나갈 때: 학번 + 확인 → 사유(소변·대변·텀블러 물 보충·기타). 기타는 "감독 선생님께 허락을 받았나요?"에 답해야 기록됩니다.
4. 돌아와서: 학번 + 확인. 잘못 누르면 10초 안에 결과 카드의 취소 버튼을 누릅니다.
5. 현황판(가로 화면 왼쪽, 세로 화면 위쪽)에 지금 자리를 비운 학생·사유·경과 분이 보이고, 사유별 기준(소변 10분·대변 15분·물 보충 5분·기타 15분, 설정에서 변경)을 넘으면 "안전 확인"으로 표시됩니다.

- 자습 시간(기본 1교시 18:30~19:50, 2교시 20:10~21:00, 3교시 21:20~23:10)에만 새 자리 비움을 받습니다. 쉬는 시간에는 나갈 때 입력하지 않아도 됩니다.
- 복귀 입력을 빠뜨린 학생이 나중에 다시 입력하면 "지금 돌아왔어요 / 그때 돌아왔고 지금 다시 나가요"를 고르게 합니다.
- 자리 비움 중 기록은 자동으로 닫지 않습니다. 현황판이나 **오늘 기록**에서 눌러 "지금 복귀로 기록" 또는 "복귀 누락으로 정리"(고친 까닭 필수)를 고릅니다.
- **학생별**(최근 7일·30일·이번 학년도 횟수, 사유별 횟수, 평균·최장 분), **최근 7일**(많은 순), **지난 날짜**(달력), **백업**(JSON·구글 드라이브·엑셀).

## 데이터

- 기록은 이 태블릿의 IndexedDB(`restroomLog`)에 학번·사유로만 저장되고, 이름은 불러온 명단에만 있습니다. 명단은 백업에 들어가지 않습니다.
- 브라우저 저장소 키는 모두 `restroom_` 접두어이고, 같은 주소의 다른 기숙사 앱 데이터·캐시는 건드리지 않습니다.
- 구글 드라이브 백업 폴더는 `태하관자리비움_백업_<학년>_<기기>`로 학년·태블릿마다 따로 생깁니다.

## 파일 구조

```
index.html         화면·저장·백업
logic.js           순수 계산(날짜·교시·자리 비움/복귀 판단·사유·통계·명단 해석·백업 검증)
sw.js              오프라인 캐시(화면·계산 파일은 네트워크 우선, 라이브러리·아이콘만 캐시 우선)
manifest.json      PWA 설정
vendor/            SheetJS 0.20.3(Apache-2.0, 라이선스 동봉)
icons/             앱 아이콘
tests/             node --test 시험(UTC·서울 두 시간대)
```

## 시험

```
npm test
```

학생 이름·명렬표·백업 파일은 저장소에 넣지 않습니다(`.gitignore`, pre-commit 검사). 시험은 "가짜"로 시작하는 이름만 씁니다.

## 사용 환경

- Android Galaxy Tab S9 FE+ (가로·세로 모두), PC 크롬
- GitHub Pages로 배포 후 브라우저에서 "앱 설치"
